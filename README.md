# Архив Тейвата

Одностраничный справочник терминов для D&D-кампании по миру Genshin Impact.

## Возможности

- Поиск и разделы для терминов и существ.
- Режим ГМа с добавлением, редактированием, удалением записей и общих заметок.
- Общая база Supabase и обновление изменений у игроков без экспорта файлов.
- Голубая палитра по референсу, повторяющийся примогем из присланного образца и вырезанные из присланных изображений Казуя и Люта.

## Режим ГМа

Пароль интерфейса: `1226`. Изменения сохраняются в общем архиве и становятся видны другим пользователям сразу.

Владелица выбрала открытые изменения без учётной записи. Поэтому пароль защищает только кнопку редактора: технически любой посетитель может обойти страницу и изменить общую базу. Не размещайте на сайте личные или чувствительные записи.
