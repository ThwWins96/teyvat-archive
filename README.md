# Архив Тейвата

Визуальный справочник терминов для D&D-кампании по миру Genshin Impact.

## Возможности

- Поиск по терминам и разделам.
- Режим ГМа: редактирование записей, создание разделов и настройка текста главной страницы.
- Общий архив кампании и кнопка «Сохранить».
- Случайная заметка на главной с возможностью выбрать другую.
- Отдельная вкладка персонажей с токенами, крупным просмотром иллюстрации и описанием.
- Голубая палитра, узор примогемов и присланные иллюстрации Казуи и Люты.

## Режим ГМа

Пароль интерфейса: `1226`.

Для архива выбраны открытые изменения без учётной записи. Пароль защищает только кнопку редактора: технически посетитель может обойти страницу и изменить общую базу. Не размещайте на сайте личные или чувствительные записи.
