# Архив Тейвата

Однофайловый визуальный справочник для кампании по D&D в мире Genshin Impact. Откройте `index.html` в современном браузере — установка и сборка не нужны.

## Возможности

- Быстрый поиск по терминам мира Тейвата.
- Режим ГМа (пароль `1226`): добавление, изменение и удаление терминов, личные заметки кампании.
- Сохранение данных в браузере; экспорт и импорт справочника в JSON для переноса между устройствами.
- Оформление по палитре из пяти оттенков: Buttercup Sky `#FFF2B2`, Dewy Blue `#A8C6E7`, Sunwashed `#FFE08A`, Cloud Puff `#FFF7D6`, Morning Breeze `#7FA8D6`. Голубой фон украшен узором из кристаллов-примогемов и силуэтами феи и совы.

## Важно о заметках

Справочник статический: данные и пароль находятся в коде страницы, а заметки хранятся только в браузере того устройства, на котором их внесли. Режим ГМа защищает от случайного редактирования, но не является надёжной защитой; не записывайте сюда секретные или чувствительные данные. Используйте экспорт/импорт, чтобы вручную переносить заметки между устройствами.

## GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch**, затем выберите ветку `main` и папку `/ (root)`. После публикации сайт будет доступен по адресу `https://thwwins96.github.io/teyvat-archive/`.
